# AZ-ZUHRI Dashboard - Real-time Edition

Modern, clean HTML dashboard for AZ-ZUHRI client performance analytics.

## Features

✅ Pure HTML + JavaScript (no build tools)
✅ Real-time data updates (every 30 seconds)
✅ Clean, professional UI
✅ Fully responsive
✅ Instant deployment

## Quick Deploy on Railway

1. Push this to GitHub
2. Connect to Railway
3. Deploy (automatic)
4. Get live URL

That's it!

## Local Development

```bash
npm install
npm start
```

Open http://localhost:3000

## Data Updates

Dashboard auto-fetches data every 30 seconds from `/api/dashboard` endpoint.

To change data, edit the `dashboardData` object in `server.js`.
